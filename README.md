# Screen Monitor AI

Система автоматического мониторинга рабочей активности с использованием ИИ. Система делает скриншоты на клиентских машинах, передает их на центральный сервер, где модель **Llava** анализирует изображение и классифицирует деятельность пользователя (Работа, Обучение, Развлечения и т.д.).

## Архитектура

1. **Client (C++):** Легковесный демон для Windows/Linux. Делает скриншоты и отправляет POST-запросы.
2. **Server (Python/Flask):** Принимает скриншоты, сохраняет их и ставит задачу в очередь.
3. **Queue (Redis):** Брокер сообщений для управления задачами.
4. **Worker (Celery):** Фоновый процесс, который взаимодействует с ИИ.
5. **AI (Ollama/Llava):** Локальная нейросеть для анализа изображений.

## Развертывание Сервера (Ubuntu / Astra Linux)

### 1. Подготовка системы

```bash
sudo apt update && sudo apt install -y redis-server python3-pip python3-venv

```

### 2. Установка ИИ (Ollama)

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llava

```

### 3. Настройка окружения

```bash
git clone https://github.com/your-repo/screen-monitor-ai.git #репозиторий закрыт. Просто переходим в папку
cd screen-monitor-ai/server
python3 -m venv venv
source venv/bin/activate
pip install -r flask celery redis requests

```

### 4. Запуск (в разных терминалах или через screen)

**Сервер:**

```bash
python3 app.py

```

**Воркер:**

```bash
celery -A app.celery_app worker --loglevel=info --concurrency=1

```

## Развертывание Клиента

### Windows 10/11

**Требования для сборки EXE:** Visual Studio 2022/2026 + C++ Desktop Development + MSVC v143 + Windows 10/11 SDK. 
Эти пункты нужны для сборки EXE-шника. Для тестирования уже готовый исполняемый файл можно запустить `screen_monitor.exe` по пути `screen-monitor-AI/screen_monitor/build/Release/screen_monitor.exe`

Если решили собрать EXE:
1. В `main.cpp` на данный момент указан IP сервера, где обрабатываются скрины.
2. Запустите `build_and_install.bat` от имени **Администратора**.
* *Что произойдет:* Проект соберется статически (один EXE), скопируется в `C:\ProgramData\WinSystemHealth` и добавится в Планировщик задач как «неубиваемый» процесс.



### Astra Linux

**Требования:** `cmake`, `libx11-dev`, `libcurl4-openssl-dev`.

1. Сборка:
```bash
sudo rm -rf build
sudo mkdir build && cd build
cmake ..
make

```

## Категории анализа

Модель Llava классифицирует(должна) активность по следующим тегам:

* **[Работа]** — IDE, офисные приложения, почта.
* **[Обучение]** — образовательные видео, статьи, документация.
* **[Соцсети]** — VK, Telegram, браузер (не по работе).
* **[Развлечения]** — Игры, YouTube, фильмы.

---

## Технические подробности

* **Формат вывода:** `[Category] Description`.
* **Интервал скриншотов:** Настраивается в `main.cpp` (по умолчанию 60 сек).
* **Отказоустойчивость:** Клиент автоматически перезапускается системой при закрытии. Сервер использует очередь Redis, чтобы не упасть при большом наплыве данных.

---

## Безопасность и приватность

* Все данные обрабатываются **локально** на вашем(моём домашнем) сервере.
* Скриншоты не отправляются в облачные API (OpenAI/Google).
* Для скрытой работы на Windows используется флаг `/SUBSYSTEM:WINDOWS`.
